# [CENCO] actualizacion de maestros en modelo productos

Herramienta base para trabajar actualizaciones de maestros en el modelo de productos de Odoo.

## Objetivo

Centralizar scripts, plantillas y documentación necesarios para preparar, validar y eventualmente ejecutar actualizaciones masivas de productos CENCO.

## Alcance esperado

- Validar archivos de entrada antes de actualizar productos.
- Documentar campos obligatorios y reglas de negocio.
- Preparar reportes de errores o advertencias antes de ejecutar cambios.
- Mantener trazabilidad de qué información se va a modificar.

## Estado

Carpeta creada como punto de partida. Aún no contiene scripts productivos.

Cuando se agreguen scripts, documentar aquí:

- Qué archivo de entrada necesita.
- Qué campos actualiza.
- Qué validaciones realiza.
- Si sólo genera reporte o si modifica datos en Odoo.
- Cómo configurar credenciales de forma segura mediante variables de entorno.
